EDIT ME, THEN COMMIT AND PUSH.

values/colors.xml          light theme colors
values-night/colors.xml    dark theme colors
values/config.xml          app name + dynamic color (Material You) on/off
drawable/ic_*.xml          every icon (24x24 vector, keep fillColor white, the app tints it)
drawable/ic_launcher_foreground.xml + colors.xml ic_launcher_background   app icon
drawable/ic_notification.xml   status bar icon

To swap an icon, replace the file with a vector drawable of the same name.
